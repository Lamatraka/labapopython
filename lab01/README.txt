Объяснение

Строка и число.
input() всегда возвращает str. Для арифметики нужны int(...) или float(...). Оператор + для строк — ("2" + "3" = "23"), для чисел — (2 + 3 = 5).

Порядок вычислений.
Приоритет: * и / раньше + и -.

Временная переменная при обмене.
first = second убирает старое значение first. Поэтому его заранее сохраняют в temp, затем переписывают first и восстанавливают second из temp.

Форматирование денег. 
(:.2f) в f-строке выводит два знака после точки: {cost:.2f} => 37.50.
